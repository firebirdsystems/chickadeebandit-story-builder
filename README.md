# Story Builder

A [Chickadee Bandit](https://chickadeebandit.com/app-library/story-builder) app.

Collaborative async storytelling — each contributor adds one part, and the full story reveals itself at the end.

## Features

- One contribution per member.
- Asynchronous; add your part whenever.
- The full story is revealed at the end.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-story-builder/releases/latest/download/bundle.json
```
